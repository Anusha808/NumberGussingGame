An interactive 3D Number Guessing Game developed using Java and JavaFX. The player tries to guess a randomly generated number and receives hints until the correct number is found or attempts run out.
- Three difficulty levels: Easy, Medium, and Hard
- Random number generation
- Higher and lower hints
- Limited attempts depending on difficulty
- Score, rounds, and wins tracking
- Play Again option
- Interactive 3D objects that respond to mouse movement and arrow keys
- Animated starfield background
- Java 17
- JavaFX
- Maven
- Java 17 or later
- Maven
1. Clone the repository:
   ```bash
   git clone https://github.com/Anusha808/NumberGussingGame.git
   ```
2. Navigate to the project directory:
   ```bash
   cd NumberGussingGame
   ```
3. Run the game:
   ```bash
   mvn clean javafx:run
   ```
